# 更新日志

本文件记录公开发布版本。每次发布以单次提交更新本仓库，并打 `vX.Y.Z` 标签。

## v0.2.3 — 2026-09-19

**本次更新**

- **生词本升级为「单元制」复习**：学习单元现在是复习的基本单位——每个单元有生词上限（默认 20 词）、
  复习轮次与完成记录。复习不再从整张生词表开始，而是按「今日复习计划」逐个单元推进：一次复习一个单元，
  完成后进入下一轮；连续两轮没有「重来」且多数词进入长间隔，单元会标记为「已掌握」，转入抽查维持。
- **自动把生词整理成单元**：收词箱里的生词可一键「智能分组」——按加入时间批次与词形相近程度
  （同前缀、拼写相近）自动划分为有上限的单元；分得不合适可一键撤销，词条回到收词箱。
- **单元抽查与不确定词专项**：已开始的单元可随机抽 5 词快验（不计入轮次进度，只记抽查结果）；
  复习中评过「重来 / 困难」的词会累计为「不确定」，可随时对该单元的这部分词做一轮专项复习。
- **长词表滚动更流畅**：单元词表改为虚拟滚动——上千词的大收词箱也只渲染可见部分，不再卡顿。

**说明**

- 已有数据自动兼容：旧生词本（含已有单元）读取后自动补齐新字段，无需迁移。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

## v0.2.0 — 2026-09-17

**改进**

- **划词开关的屏幕反馈**：用快捷键（默认 Ctrl+Alt+D）或托盘菜单开关划词后，会在光标旁短暂提示
  「划词已开启 / 划词已关闭」——此前状态只体现在托盘菜单的勾选上，屏幕上没有任何反馈。
- **快捷键录制告警**：设置页「快捷键」子页录制的组合键若不含 Ctrl / Alt（例如 Shift+W），
  会在行下提示「会向当前应用输入字符（可编辑处会覆盖选区）」，建议改用含 Ctrl 或 Alt 的组合。
- **触发方式说明**：设置页「划词助手」选择「按住 Ctrl 查词」或「快捷键查词」时，行下会说明
  各自的触发动作，并点明这两种方式下**拖选 / 双击不再触发**浮标。

**说明**

- 版本号格式调整：自本版起第二、三位各为一位数字（如 `0.2.0`），便于阅读；应用内更新不受影响。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

## v0.1.16 — 2026-09-15

**新增**

- **应用内更新**：设置页新增「关于」子页——检查更新、下载新版本（显示进度）、确认后安装并自动重启；
  更新包经签名校验，校验不通过不会安装。可开启「启动时检查更新」（默认关闭）。
- **开机启动**：设置页「通用」子页新增开关（默认关闭）——登录 Windows 后自动启动并静默驻留托盘。

**说明**

- 自动更新自本版开始生效：v0.1.15 及更早版本需手动安装本版一次。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**改进**

- 便携模式（exe 同目录放置 `onedict.portable`）下不提供在线更新，避免便携副本被装成安装版。
