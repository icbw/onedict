# onedict v0.2.0

**改进**

- **划词开关的屏幕反馈**：用快捷键（默认 Ctrl+Alt+D）或托盘菜单开关划词后，会在光标旁短暂提示
  「划词已开启 / 划词已关闭」——此前状态只体现在托盘菜单的勾选上，屏幕上没有任何反馈，
  容易误判成「按了没反应」。
- **快捷键录制告警**：设置页「快捷键」子页录制的组合键若不含 Ctrl / Alt（例如 Shift+W），
  行下会提示该键会向当前应用输入字符、可能覆盖选区，建议改用含 Ctrl 或 Alt 的组合。
- **触发方式说明**：设置页「划词助手」在选择「按住 Ctrl 查词」（按住 Ctrl 约 0.35 秒）或
  「快捷键查词」时，行下会说明触发动作，并点明这两种方式下**拖选 / 双击不再触发**浮标。

**说明**

- 版本号格式调整：自本版起第二、三位各为一位数字（如 `0.2.0`），便于阅读；应用内更新不受影响。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
