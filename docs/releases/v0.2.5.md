# onedict v0.2.5

**新功能**

- **截图翻译「识别后自动翻译」**：设置页「截图助手」新增开关（默认关闭）。开启后截图识别完成即自动
  开始逐行翻译，不用再点工具条「译」——与「截图后自动识别」叠加，拖框后译文自动逐行替换原文。
  目标语言仍取设置页「翻译目标」默认值；AI 图译兜底完成后仍需手动翻译。

**说明**

- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
