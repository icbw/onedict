# onedict v0.2.4

**修复**

- **本地词典发音优先恢复**：点词条里的喇叭时，会先播词典自带的真人录音。此前本地发音取不出来时
  会悄悄改用在线合成语音（听起来就是「本地发音没生效」），且不说明原因；现在只有词典确实没收录
  该词才会静默改用合成语音，本地音频取不出来时会明确说出原因。
- **发音失败提示不再误导**：此前任何播放失败都提示「浏览器阻止了自动播放」，连点两个喇叭时还会
  冒出与本次点击无关的同款提示。现在按真实原因提示，且只反馈当前这次点击的结果。

**说明**

- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
