# onedict v0.1.16

- 平台：Windows x64
- 安装包：`onedict_0.1.16_x64-setup.exe`（NSIS）
- 发布日期：2026-09-15

安装包未做代码签名，SmartScreen 可能提示，选择「仍要运行」即可。

## 本次新增

- **应用内更新**（设置 → 关于）：检查更新、下载新版本（显示进度）、确认后安装并自动重启；
  可在关于页开启「启动时检查更新」（默认关闭）。更新包经签名校验，校验不通过不会安装。
- **开机启动**（设置 → 通用）：登录 Windows 后自动启动 onedict 并静默驻留系统托盘（默认关闭）。

## 说明

- 自动更新自本版开始生效：v0.1.15 及更早版本需要手动安装本版一次。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。
- 便携模式下不提供在线更新（程序与数据在自有目录，更新即替换该目录，由用户自行处理）。
