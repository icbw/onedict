# onedict v0.2.8

**新功能**

- **划词「查检」动作**：在任意应用里选中文字，浮标即可「查检」——当场列出中英文排版
  （中英空格、全半角标点）、用语与 AI 式表达（套路开头、空洞强调、机械总结等）问题，
  可复制单条建议或合并复制修复后的全文，回原处粘贴。在设置页「划词助手」中启用
  （默认关闭）；纯本地规则检查，不联网、不需要配置模型。
- **主窗口新增「检查」页签**：粘贴或输入整篇长文，停顿后自动检查——问题在编辑区内
  以波浪线标出，点击结果列表跳到原文对应位置；逐条「修复 / 忽略」，或一键全部修复。
  左侧分类栏按「排版 / 错别字 / 术语 / 文风 / AI 腔」过滤，附计数。
- **术语表**：自建「禁用词 → 首选词」替换规则（如 nodejs → Node.js、登陆 → 登录），
  保存后立即对当前文本生效，大小写不敏感；条目可停用、可调级别（提示 / 建议 / 错误）。
- **英文拼写检查**：以本地词典收录为准，屈折变形（复数、时态、进行式）自动还原后
  判定；缩写（NASA）、驼峰标识符（JavaScript）与句中专名自动豁免，专有名词可一键
  加入白名单。需要已启用至少一部英文词典，未启用时拼写检查自动跳过，其余检查照常。
- **忽略不复发**：点过「忽略」的问题按「规则 + 原文片段」记忆，重启应用、再查同一段
  文字都不会再提示；可在「已忽略」管理页逐条恢复或全部恢复。
- **生词语境管理**：生词本里的语境（原句与来源）现在可以查看、编辑和清除——清除时
  连带清掉卡面上由原句生成的中文对译，不留隐私残留；Anki 导出可选附带语境两列；
  模型服务页新增「生词卡 AI 兜底例句」开关（默认关闭）。

**修复**

- **在线发音更稳**：Edge 在线语音所选音色暂不可用时自动挑选兼容音色（此前会静默
  改用系统合成音，听起来就是「在线发音没生效」）；瞬时网络抖动自动重试一次；确实
  降级到系统语音时，页面会说明「在线语音不可用，已改用系统语音」。
- **查词面板清除按钮**：词头输入框右侧新增一键清除，清空词头与全部词典结果。

**说明**

- 检查功能的「AI 式表达」是可读性建议（描述特征），不代表或鉴定文本由谁撰写。
- 检查数据（术语表 / 白名单 / 忽略清单 / 检查记录）保存在本地，且已纳入设置页的
  备份与恢复；检查记录只保存问题清单与摘要，不保存原文。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
