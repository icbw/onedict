# onedict v0.2.1

**修复**

- **文字版词典的排版还原**：部分「文字版 / 精排版」词典（如《漢語大詞典》文字版、
  《汉语大词典》简体精排）的词条里会混入 `` `20` `` `` `9` `` 这类反引号数字，
  夹在正文之中影响阅读。现在会按词典自带的样式表还原：词头、拼音与注音、
  义项编号、书证引文各自恢复应有的字号、颜色与分隔，整条释义的观感与排印本一致。

**说明**

- 仅调整这类词典的显示方式：词典文件本身不被修改，查询、生词本、偏好与查词历史不受影响。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
