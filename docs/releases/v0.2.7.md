# onedict v0.2.7

**新功能**

- **生词卡复习卡面全新改版**：复习翻面后不再直接展示词典整页，改为规则化学习卡面——
  置顶仍是收藏时的语境义与原句（词形高亮），下方按常用度列出该词的多条释义与例句。
- **释义与例句复用词典内容**：本地《牛津高阶双解》的义项与例证、在线剑桥（义项绑定
  例句对译）、必应（释义串与例句区）、有道（简明释义）按词典常用度合并去重；
  各词典都没有的词才由 AI 兜底生成，并在卡面明确标注。词组（如 debris flow）
  第一部词典查不到时，会自动从其他词典与在线源拿到释义，不再显示「未收录」。
- **词典式排版**：词性按词典惯例着色（名词蓝 / 动词绿 / 形容词琥珀 / 副词紫），
  每条释义标注来源词典，双解来源同时显示英文定义。
- **中文对译一键展开**：语境原句与例句的中文对译默认隐藏（回忆时不受干扰），
  点卡面右上角「译」按钮展开。
- **老生词自动补齐**：升级后打开应用，已有的生词会在后台按低速率逐个自动整理卡面，
  无需任何操作；之后新收藏的词在入库时即完成整理。

**说明**

- 卡面整理需要联网（查询在线词典）；未配置模型服务也能正常使用（AI 仅兜底场景）。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
