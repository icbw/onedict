# onedict v0.1.15（首次公开发布）

- 平台：Windows x64
- 安装包：`onedict_0.1.15_x64-setup.exe`（约 4.4 MB，NSIS）
- 发布日期：2026-09-10

安装包未做代码签名，SmartScreen 可能提示，选择「仍要运行」即可。

## 本次修复

- 词典页搜索历史在冷启动后需先查询一次才显示
- 翻译页可能停留「未配置模型服务」空态
- 划词动作栏动作数量与设置页不一致

## 本次改进

- 启动期偏好与数据初始化时序修复，读取更稳定
- 翻译页支持跨服务商选择模型

## 已知情况

- 仅支持 Windows x64；安装包未做代码签名
- 本地词典语料（MDX/MDD）需自行准备，放入应用数据目录下的 `dicts/`
