# onedict v0.2.2

**改进**

- **导航选中态改为描边式**：主窗口左侧导航栏的选中项，从「品牌色实心方块 + 白色图标」
  改为「品牌色描边 + 淡色底 + 品牌色图标」，与设置页导航的选中样式（左侧短条 + 文字加重）
  观感统一——界面更轻，当前位置依然一目了然。

**说明**

- 纯界面调整：功能、词典引用、生词本、偏好与查词历史均不受影响。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
