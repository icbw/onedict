# onedict v0.2.6

**新功能**

- **生词收藏带上原句语境**：从 Word、浏览器等应用划词收藏生词时，自动保存该词出现的原句
  （连同来源应用与时间）。查过的词在哪个句子里遇到、用的是什么意思，收进生词本的就是那个样子。
- **复习卡语境再现**：有语境的生词，复习正面不再是孤零零的单词，而是原句中被挖空的那个词——
  在原句语境里回忆它；翻面后置顶显示收藏时的释义与原句（词形高亮）。没有语境的词照旧显示单词。
- **释义级收藏**：词典页内拖选一段释义文本，浮出「查 / 收藏此义」小工具条——收藏的不只是词头，
  还有你在意的那个词义；该词再次收藏时主复习词义随之更新。拖选只为复制时也不再触发自动查词，
  双击选词查词照旧。
- **复习语音与缓存**：复习卡正面可朗读整句（Edge 在线自然语音，断网降级本地合成）；设置页
  「发音」新增「复习语音预取」开关（默认关闭）——开启后提前把今日复习的词与例句合成到本地缓存，
  复习时即点即播，断网也有在线音质。

**说明**

- 老生词本自动兼容：没有语境的词照常复习，无需迁移。
- 语境保存在本地，仅自己可见。
- 更新不影响本地数据：词典引用、生词本、偏好与查词历史均保留。

**安装**

- Windows x64；安装包未做代码签名，SmartScreen 提示请选「更多信息 → 仍要运行」。
- 已有安装版可在设置页「关于」中检查更新直接升级（v0.1.16 及以上支持）。
